# Poker Dice 🎲
## Introduction
This is a simple implementation of poker dice, written in C. I wrote this a while ago!

Each game begins by rolling 5 dice. The user then selects which are to be re-rolled, after which the hand is evaluated.

## Improvements
- Build a graphical user interface.
- Switch from using numbers to dice pips or classic poker dice faces (9, 10, J, Q, K, A).
- Add support for multiple players, who can compete against each other.
